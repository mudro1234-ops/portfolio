Selected projects

Applied projects built around real problems in informal trade and agriculture.

VendAI

WhatsApp demand forecasting and inventory system for informal traders. Final-year research project.

  • Traders record sales and stock in plain language or through a simple menu, and receive stock levels and restock advice by reply.
  • Built a conversation engine with free-text and menu parsing, and a moving-average demand forecast.
  • Developed a web MVP with a chat interface for traders and an admin dashboard for agent-assisted registration.
  • Supports English, Shona and Ndebele. Designed for vendors in Gweru, Bulawayo and Harare.

Built with: Python, Flask, SQLite, WhatsApp Business API (simulated in prototype)

AgriShield

USSD drought and pest micro-insurance for smallholder farmers. MSU Enovate4Impact, Insuretech stream.

  • Farmers register by USSD. Payouts are triggered automatically when satellite and climate data cross a drought threshold, with no claim forms.
  • Combines Sentinel-2 vegetation index data, NASA POWER climate data and an XGBoost drought-risk model.
  • Payouts delivered through mobile money. Four user roles: farmer, field agent, admin and faculty reviewer.
  • Selected for the pitch round. Field pilot planned in Chiwundura and Gweru rural.

Built with: Supabase, XGBoost, USSD, EcoCash and Innbucks integration (planned), GitHub
